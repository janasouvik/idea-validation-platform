# ProblemPulse — Frontend Client

A responsive, editorial web client for the ProblemPulse Problem Discovery & Validation Platform.

## Technology Stack
- **React 19**
- **TypeScript**
- **Vite**
- **React Router**
- **Lucide Icons**
- **Custom Modern Editorial CSS Design System**

## Development
```bash
npm install
npm run dev
```

Server runs on `http://localhost:5173` (or next available port) and proxies all `/api` requests to backend on `http://localhost:5001`.

## Production Build
```bash
npm run build
npm run preview
```
